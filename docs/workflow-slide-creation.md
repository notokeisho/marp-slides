# スライド作成ワークフロー

このドキュメントは、AIエージェントが「スライド作成して」とリクエストされた時に従うワークフローです。

## トリガーとなるユーザーリクエスト

以下のようなリクエストを受けた場合、このワークフローを実行してください：

- 「スライド作成して」
- 「新しいスライドを作りたい」
- 「プレゼン作って」
- 「発表資料を作成して」

## ワークフロー

### ステップ 1: ファイル名を質問

```
スライドを作成しますね！

まず、ファイル名を教えてください（拡張子なし）。
例：project-report, team-meeting, product-launch
```

**ユーザーの回答を待つ**

### ステップ 2: テーマを質問

```
テーマを選んでください：

1. default - シンプルな標準テーマ（ビジネス向け）
2. gradient - 紫のグラデーション（華やかなデザイン）
3. darkmode - ダークモード（技術系向け）

番号または名前で教えてください。
```

**ユーザーの回答を待つ**

### ステップ 3: スライド内容を質問

```
スライドの内容を教えてください。

例えば：
- 「タイトル、目次、本編3枚、まとめ」
- 「プロジェクト進捗報告：背景、現状、課題、今後の予定」
- 「製品紹介：特徴、メリット、価格、お問い合わせ」

どんな内容にしますか？
```

**ユーザーの回答を待つ**

### ステップ 4: スライドファイル作成

`make new` コマンドを実行します。

```bash
make new
```

**インタラクティブ入力：**
1. ファイル名 → ステップ1でユーザーが指定した名前を入力
2. テーマ選択 → ステップ2でユーザーが選んだテーマを選択

### ステップ 5: スライド内容の編集

生成された `slides/[ファイル名].md` を開き、ユーザーが指定した内容に基づいてMarkdownを編集します。

**編集のポイント：**
- タイトルスライドには `<!-- _class: title -->` を使用
- スライドは `---` で区切る
- 画像は `![width:500px](../../assets/image.png)` 形式
- 箇条書き、表、コードブロックなど適切に活用

**Markdown構文の参考：** [使い方ガイド](usage.md)

### ステップ 6: ビルド実行

```bash
make build
```

または、単一ファイルのみビルドする場合：

```bash
make build-one FILE=slides/[ファイル名].md
```

### ステップ 7: 完了報告

```
✅ スライドが完成しました！

生成されたファイル：
- PDF: dist/pdf/[ファイル名].pdf
- PowerPoint: dist/pptx/[ファイル名].pptx
- HTML: dist/html/[ファイル名].html

確認するには以下のコマンドを実行してください：
open dist/pdf/[ファイル名].pdf

修正が必要な場合は、お知らせください。
```

## 追加リクエストへの対応

### 「修正して」「変更して」

1. 対象ファイルを確認（不明なら質問）
2. 修正内容を確認（不明なら質問）
3. `slides/[ファイル名].md` を編集
4. `make build` で再ビルド
5. 変更内容を報告

### 「画像を追加して」

1. 画像ファイルの場所を確認
2. `assets/` に画像がある場合：`![width:500px](../../assets/画像名.png)`
3. Markdownに画像を挿入
4. 再ビルド

### 「テーマを変えて」

1. `slides/[ファイル名].md` のFront Matterを編集
2. `theme:` の値を変更（default / gradient / darkmode）
3. 再ビルド

## エラー時の対応

### make new が失敗

```
❌ スライド作成でエラーが発生しました。

セットアップが完了していない可能性があります。
「セットアップして」と言ってください。
```

### make build が失敗

```
❌ ビルドでエラーが発生しました。

エラー内容：
[エラーメッセージ]

考えられる原因：
1. Front Matterの形式が正しくない（`---` で囲まれているか）
2. 画像パスが間違っている
3. Markdown構文エラー

修正が必要な箇所を特定しますか？
```

## 注意事項

- **必ず質問する**: ファイル名、テーマ、内容は推測せず必ず質問
- **makeコマンドのみ使用**: npm等の直接コマンドは使わない
- **スライドファイルのみ編集**: `slides/` と `assets/` 以外は編集しない
- **システムファイル保護**: themes/, scripts/, Makefile等は絶対に変更しない
