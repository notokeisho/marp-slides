# セットアップワークフロー

このドキュメントは、AIエージェントが「セットアップして」とリクエストされた時に従うワークフローです。

## トリガーとなるユーザーリクエスト

以下のようなリクエストを受けた場合、このワークフローを実行してください：

- 「セットアップして」
- 「初期設定して」
- 「環境構築して」
- 「インストールして」
- 「使えるようにして」

## ワークフロー

### ステップ 1: 事前確認

ユーザーに以下を確認してください：

```
セットアップを開始します。
Node.js (v18以上) はインストールされていますか？

1. はい、インストール済みです
2. いいえ / わかりません
```

**ユーザーが「いいえ」または「わかりません」と答えた場合：**

```
Node.jsのインストールが必要です。
以下のURLからダウンロードしてインストールしてください：
https://nodejs.org/

インストール後、もう一度「セットアップして」と言ってください。
```

ここでワークフローを終了します。

### ステップ 2: セットアップ実行

以下のコマンドを実行してください：

```bash
make install
```

### ステップ 3: 結果確認

コマンドが成功した場合、ユーザーに以下を報告してください：

```
✅ セットアップが完了しました！

以下のパッケージがインストールされました：
- @marp-team/marp-cli（スライドビルド用）
- inquirer（インタラクティブUI用）

これで以下のことができます：
- 「スライド作成して」→ 新しいスライドを作成
- 「ビルドして」→ PDF/PPTX/HTMLを生成

何をしますか？
```

### ステップ 4: エラー時の対応

コマンドが失敗した場合：

1. エラーメッセージを確認
2. 以下をユーザーに報告：

```
❌ セットアップ中にエラーが発生しました。

エラー内容：
[エラーメッセージをここに表示]

対処方法：
1. Node.jsがインストールされているか確認してください
2. ターミナルで `node --version` を実行してバージョンを確認してください（v18以上が必要）
3. 問題が解決しない場合は、docs/troubleshooting.md を参照してください
```

## 注意事項

- **makeコマンドのみ使用**: `npm install` 等の直接コマンドは使わない
- **エラー時は質問**: 不明点はユーザーに確認する
- **詳細は setup.md 参照**: より詳しい情報が必要な場合は setup.md を読む
